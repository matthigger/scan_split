Files are stacked in name order. Page layout, page count and headers are learned from the scans; nothing needs to be set up.

    1 · Page types

    Each card is the average of every sheet of that type (handwriting fades out, the printed page remains); the magnifier shows it large. A type's name is its output file. Split a type that hides two versions, merge to undo; names and routing are kept either way. Backs always travel with their front.

    2 · Review sheets

    Click to select (shift-click for a range), then re-route the selection. Double-click or ⤢ to inspect a sheet.
